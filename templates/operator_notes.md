# Operator notes

Append here at any time while the run is going. The agent reads this at the
start of every round and must acknowledge each new note in that round's plan.

Use it to inject a lead, redirect a strategy, or flag a false trail. No restart
needed.

Notes outrank the agent's own frontier scoring. They do not override the gates
in MANUAL §12 or the banned behaviours in §17.

Format: one note per bullet, newest at the bottom.
